# CLI Tip Calculator & Unit Converter

This is a command-line interface (CLI) application built in Python. It serves as the capstone project for Week 1 of my software engineering roadmap, demonstrating core Python concepts like custom functions, user input handling, and f-string formatting.

## How It Works

The script contains two distinct mathematical utilities that run sequentially:

1. **Tip Calculator**
   * **Purpose:** Calculates the exact tip amount and total bill based on a custom tip percentage.
   * **Logic:** Applies the formula `Tip Amount = Bill * (Tip Percentage / 100)` and adds it to the base bill.

2. **Unit Converter**
   * **Purpose:** Converts a given distance from kilometers into miles.
   * **Logic:** Multiplies the inputted kilometers by the standard conversion rate (`0.621371`).

## How to Run
To test the application, ensure you have Python installed, open your terminal, and run:
python main.py
