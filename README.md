# Python Learning Projects

This repository contains my weekly projects for my Software Engineering roadmap, focusing on Python, Linux, and Git branching workflows.

## Directory Structure
* **`week1_calculator/`**: A CLI Tip Calculator and Unit Converter demonstrating custom functions, user input handling, and f-string formatting.
* **`week2_guessing_game/`**: A CLI Number Guessing Game demonstrating `while` loops, `if/elif/else` control flow, and `try/except` error handling.
